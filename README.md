# PhotoKit · 本地版

带首页的多功能工具站，第一个模块是「图片转 PPT」。所有处理在本机/浏览器完成，图片不上传、不调用模型。

## 启动

双击 `start.command` 启动项目；再次双击会自动重启。

停止服务：双击 `stop.command`，或终端运行：

```bash
./stop.command
```

也可以直接终端运行：

```bash
./start.command
```

然后浏览器打开 `http://127.0.0.1:8765`。

> 端口固定 8765（与旧版网页工具同源，便于迁移旧作品）。如果旧工具还在运行，请先停掉它。

## 功能

**首页**：功能模块入口，预留多功能扩展位。

**图片转 PPT 模块**：
- 项目列表（卡片墙）：封面、名称、图片数、更新时间、导出次数
- 新建 / 打开 / 重命名 / 删除项目
- 导出 / 导入项目包（zip），用于备份与跨机迁移
- 「迁移旧作品」：从旧版网页工具的浏览器存储导入已有作品
- 编辑页：小红书链接抓图、本地上传/拖拽、缩略图管理、版式设置、生成竖版 PPT
- 所有改动自动保存到项目文件包
- **PPT 保存规则**：首次生成在 `导出/` 目录创建专属文件（项目名_01.pptx、项目名_02.pptx…），再次生成直接覆盖同一文件，不会重复产生多个文件；编辑页显示完整路径，列表页可下载 PPT 或备份整个项目包
- **参数模板（拍摄技巧）**：版式设置里下拉选「参数模板」，生成 PPT 时每张图下方预留一个填写框，框内印好该模板的摄影参数字段（标签＋下划线），下载后用 PowerPoint/WPS 填空。点「⚙ 维护」可增删改模板及字段，模板库存全局 `参数模板.json`，所有项目共用。预置 6 套：人像基础参数/光线与构图/风格与调色/完整拍摄笔记/极简单行/纯空框
- **四季主题（一键美化）**：版式设置顶部点色卡切换整套视觉风格——🌸春·樱绿 / ☀️夏·海蓝 / 🍁秋·枫红 / ❄️冬·雪蓝，另有「原版」沿用旧样式。切换后自动套用背景色、标题墨色、强调色、标注框配色与页码色；季节主题还会加顶部/底部色条、图片细描边，标题页带季节大字水印与英文标签。主题随项目保存，下次打开仍是上次选的；选完仍可手动改「背景色」微调。

## 项目文件包

每个项目在 `项目库/` 下是一个独立目录：

```
项目库/<id>/
  project.json   元数据 + 版式设置 + 图片清单 + 导出记录
  images/        原始图片
  output/        导出的 PPT
  cover.jpg      列表封面
```

一个文件夹 = 一个项目，可直接拷贝备份或压缩分享。

## 目录结构

```
PhotoKit/  （磁盘目录名仍为「摄影工具站」）
  index.html                  首页
  assets/site.css             公共样式
  server.py                   本地服务（静态托管 + 项目 API + 抓图）
  modules/img2ppt/
    index.html                项目列表页
    editor.html               项目编辑页
    storage.js                存储适配层
    vendor/pptxgen.bundle.js  PPT 生成库
  项目库/                     项目文件包存放
  导出/                       PPT 导出目录（项目名_编号.pptx）
  start.command               双击启动 / 再次双击重启
  stop.command                双击停止
```

## 说明

- 抓图依赖本机 `agent-browser`；遇到小红书风控可重试或换网络。
- **抓取规则可维护**：小红书改版导致抓不到图时，点抓图区「⚙ 抓取规则」，按从上到下顺序逐条尝试。默认两条：① CSS 选择器 `.img-container img`（稳定，抓正文图）；② 链接关键词兜底。可增删/改值/调顺序/启停，存全局 `抓取规则.json`。抓取后状态栏会显示"命中规则：xxx"，方便判断哪条生效。
- PPT 不再弹「另存为」，统一保存到站点 `导出/` 目录；文件名按项目分配 `_01`、`_02` 后缀，同一项目再次生成覆盖自己的文件。列表页「下载PPT」可把文件取到本地任意位置。
- 公网版（另一目录）本轮未改造，仍是旧版单页工具。
